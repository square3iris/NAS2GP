## 2026-08 〜 2026-10 — Web UI 一本化期 (v1.7.x / 現行)

- **デスクトップ GUI (PySide6) を完全撤去し、Web UI に一本化**。`entry_web.py` が標準エントリ。
- Web UI は **7 ページ構成** (ホーム / コンソール / 設定 / 端末 / 管理 / 統計 / 診断) を共通 `base.html` で統一。
- **多言語対応 (日本語 / 英語)** を Web UI・コンソール出力の両方に適用。`config/lang/*.json` による外部言語追加に対応。
- **設定画面をスキーマ駆動化**。バッチ工程 (①〜⑦) 順の **9 グループ** に再編し、各グループ／項目に「どの工程か」「変えるとどう動くか」の説明を常時表示。バッチサイズの GB 単位編集に対応。
- **統計ページ**を分析専用化し、期間切替 (24時間 / 7日 / 30日) の時系列グラフ (転送量 / 件数 / 速度 / 電池 / 温度) を自作 SVG で表示。ファイル一覧と列独立フィルタ (転送 / GP / 削除)・ページングは **管理ページ** へ移設 (14 万件超でも高速応答)。
- **診断ページ** (デバイス情報 / DB 状態 / 言語整合性 / バグレポート ZIP) と **管理ページ** (3 OPEN + 3 RESET) を追加。
- **ADB 接続の安定化**: 見せかけ接続 (device 表示でも実疎通不可) を shell probe で検知。
- **コンソールログの Web 表示**: `_WebTee` で stdout/stderr をキャプチャし SSE 配信。ノイズ行は抑制。
- **ホーム画面**: ステータスバナー (信号機スタイル) / バッチ内 7 工程インジケータ / 接続デバイスとヘルス情報 (空き容量・温度・バッテリー) を 30 秒周期で表示。
- **制御**: 開始 / 停止 / 今回のバッチで終了 を実装。リセットはすべて OLD rename 方式で安全に退避。
- **転送済みファイル削除**時に DB の削除状態を `DONE` に同期する整合処理を追加。
- 起動時に `uvicorn` のアクセスログを抑止し、`Ctrl+C` は `timeout_graceful_shutdown=3` で速やかに停止。

### v1.7.18 / v1.7.19 — 長時間運転の安定化 / 統計グラフと設定再編

- **長時間運転の安全ゲート (v1.7.18)**: 転送前に電池残量を確認し、閾値未満かつ非充電なら待機 → 上限超過で安全停止 (`BATTERY_LOW_THRESHOLD_PCT` / `BATTERY_WAIT_MAX_SEC`)。ADB 切断時は一定時間再接続を粘り、復旧不能なら失敗分を `PENDING` に戻して安全停止 (`ADB_RECOVERY_WAIT_SEC`)。通常運転のオーバーヘッドを抑えるため、接続確認は転送失敗時のみ実施 (オンデマンド)。
- **切断解析ログ (v1.7.18)**: 同期中に 10 分間隔で残量 / 温度 / 空き容量を `logs/health.jsonl` へ記録 (ハートビート)。復旧不能な切断時は `logs/disconnect_*.log` にスナップショットを保存し、電池切れか突発切断かを事後に切り分け可能。
- **統計ページの分析専用化と時系列グラフ (v1.7.19)**: 期間切替 (24時間 / 7日 / 30日) 付きの自作 SVG グラフ 5 種 (転送量 GB/h・件数 (写真/動画)・実効速度 MB/s・電池残量・温度)。新 API `/api/stats/timeseries`。
- **転送完了時刻の記録 (v1.7.19)**: `files.transferred_at` を転送 DONE 時に記録 (件数の時間別集計用)。索引を追加。
- **ファイル一覧の移設 (v1.7.19)**: 統計ページから **管理ページ** へ移設 (列ごとの絞り込み / 検索 / 並べ替え)。
- **設定ページの再編 (v1.7.19)**: バッチ工程順の 9 グループに再構成し、各グループ／項目に説明を常時表示。難解な内部用語 (旧来の挙動 / 受理ルール B 等) を平易な表現に置換。

### v1.13.0 — 同期運転中 の 画面 減光 (常夜灯モード の 実装)

- **Google Photos 「準備中 / スキャン中」 の 認識 (v1.14.2)**: バックアップ が 「バックアップ の 準備中 / フォト ライブラリ を スキャン して い ます」 を 表示 し て 長 時間 停滞 する 状態 を `unknown` と 混同 し て い まし た。 `device/ui.py::is_preparing_backup()` で `preparing` と し て 分離 し 、 正当 な 待機 と し て 扱う こと で 、 不要 な 警告 ログ の 連投 や 強制 復旧 (画面 復帰 / アプリ 再起動) を 抑止 し ま す 。
- **端末 データ 削除 ボタン の 「処理中」 表示 (v1.14.2)**: Web UI の 端末 データ 削除 ボタン 押下 時 に スピナー 付き オーバーレイ を 表示 し 、 処理 中 の 明示 と 二 重 送信 防止 (disabled) を 行い ます (ADB 経由 の 削除 に 時間 が かかる ため)。
- **保護 停止 の 表示 を ユーザー 操作 と 区別 (v1.14.2)**: 電池 / 温度 の 保護 停止 は `control.request_stop_now(reason="protection")` で 理由 を 記録 し 、 バッチ ループ 終了 時 の メッセージ を 「ユーザー 要求 により 終了」 で は なく 「[安全停止] 保護 機能 (電池 / 温度) により … 終了」 に 変更 し まし た (従来 は 保護 停止 も ユーザー 操作 と し て 表示 さ れ 、 停止 理由 が 誤って 伝わっ て い まし た)。
- **停止 要求 で の バックアップ 確認 中断 を NG 扱い し ない (v1.14.2)**: 工程⑤/⑥ の 完了 確認 が 停止 要求 (保護 停止 / ユーザー 操作) で 中断 さ れ た 場合 、 バックアップ 自体 の 失敗 で は ない ため `[Phase 5/6 NG]` 警告 を 出さ ず 、 `[Phase 5/6 中断]` の 情報 ログ に 変更 し ま し た (保護 停止 の 巻き添え で エラー の よう に 見え て い まし た)。
- **電池 閾値 を 設定 画面 から 変更 可能 に (v1.14.2)**: 従来 は コード 内 の 固定 値 だっ た 電池 の 「復帰 閾値」 (`BATTERY_LOW_THRESHOLD_PCT`、 既定 20% → 30%) と 「停止 閾値」 (`BATTERY_CRITICAL_PCT`、 既定 10% → 15%) を 設定 画面 の 電池 グループ から 変更 でき る よう に し ま し た。 あわせ て 回復 待ち の 間 に 残量 を 読み直す 間隔 (`BATTERY_WAIT_POLL_MIN`、 既定 10分) を 新設 し 、 待機 ループ は この 間隔 で 残量 を 読み直し ます (停止 要求 に は 待機 中 でも 1秒 以内 に 応答)。 設定 は `config/config_ui.json` に 保存 さ れ 、 既存 config に は 不足 キー と し て 既定 値 が 自動 補完 さ れ ます 。
- **待機中 ・ 非 UI 工程 の 画面 消灯 (v1.14.2)**: 充電 効率 の 改善 の ため 、 画面 を 見る 必要 の ない 区間 (転送 中 / メディア スキャン / 削除 / 電池 ・ 温度 の 回復 待ち / バックアップ 状態 の 確認 と 確認 の 間) は 端末 の 画面 を 消灯 する よう に し まし た。 新 設定 `SCREEN_OFF_WHEN_IDLE` (既定 ON、 設定 画面 の 画面 グループ) で 制御 し 、 OFF の とき は 従来 どおり 減光 のみ に な り ま す 。 高頻度 で 呼ん でも 再送 は 60 秒 間隔 に 間引か れ 、 画面 を 起こす たび (`wakeup`) に タイムスタンプ が リセット さ れ る ため 、 点灯 / 消灯 の スラッシング は 起き ま せ ん 。 Google Photos の アップロード は 画面 を 消し た まま でも 継続 し 、 また 電池 低下 で 停止 中 の 端末 が 点灯 した まま だ と 充電 が 著しく 遅く なる ため 、 特に 保護 停止 中 の 待機 で 効果 が あり ま す 。
- **Google Photos 監視 周期 の 見直し (v1.14.2)**: `BACKUP_CHECK_INTERVAL` の 既定 を `8` 秒 → `30` 秒 、 `BACKUP_STALLED_LIMIT` の 既定 を `15` → `5` に 変更 し まし た 。 1 周期 は 「確認 処理 (画面 ON + dump) + 間隔」 の ため 、 周期 を 伸ばす こと で 画面 の 点灯 率 を 約 33% → 約 12% に 削減 し 、 充電 を 妨げ にくく し ま す 。 停滞 リスタート の 実 時間 は 従来 と ほぼ 同等 (5 回 × 30 秒 ≒ 150 秒) で す 。 無進捗 の 打ち切り は 時間 基準 の ため 周期 変更 の 影響 を 受け ま せ ん 。
- **バージョン 更新 (v1.14.2)**: `settings.APP_VERSION` を `1.14.1` → `1.14.2` に 変更。
