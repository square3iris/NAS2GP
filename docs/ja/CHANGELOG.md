## 2026-08 〜 2026-10 — Web UI 一本化期 (v1.7.x / 現行)

- **デスクトップ GUI (PySide6) を完全撤去し、Web UI に一本化**。`entry_web.py` が標準エントリ。
- Web UI は **7 ページ構成** (ホーム / コンソール / 設定 / 端末 / 管理 / 統計 / 診断) を共通 `base.html` で統一。
- **多言語対応 (日本語 / 英語)** を Web UI・コンソール出力の両方に適用。`config/lang/*.json` による外部言語追加に対応。
- **設定画面をスキーマ駆動化**。バッチ工程 (①〜⑦) 順の **9 グループ** に再編し、各グループ／項目に「どの工程か」「変えるとどう動くか」の説明を常時表示。バッチサイズの GB 単位編集に対応。
- **統計ページ**を分析専用化し、期間切替 (24時間 / 7日 / 30日) の時系列グラフ (転送量 / 件数 / 速度 / 電池 / 温度) を自作 SVG で表示。ファイル一覧と列独立フィルタ (転送 / GP / 削除)・ページングは **管理ページ** へ移設 (14 万件超でも高速応答)。
- **診断ページ** (デバイス情報 / DB 状態 / 言語整合性 / バグレポート ZIP) と **管理ページ** (3 OPEN + 3 RESET) を追加。
- **ADB 接続の安定化**: 見せかけ接続 (device 表示でも実疎通不可) を shell probe で検知。
- **コンソールログの Web 表示**: `_WebTee` で stdout/stderr をキャプチャし SSE 配信。ノイズ行は抑制。
- **ホーム画面**: ステータスバナー (信号機スタイル) / バッチ内 7 工程インジケータ / 接続デバイスとヘルス情報 (空き容量・温度・バッテリー) を 30 秒周期で表示。
- **制御**: 開始 / 停止 / 今回のバッチで終了 を実装。リセットはすべて OLD rename 方式で安全に退避。
- **転送済みファイル削除**時に DB の削除状態を `DONE` に同期する整合処理を追加。
- 起動時に `uvicorn` のアクセスログを抑止し、`Ctrl+C` は `timeout_graceful_shutdown=3` で速やかに停止。

### v1.7.18 / v1.7.19 — 長時間運転の安定化 / 統計グラフと設定再編

- **長時間運転の安全ゲート (v1.7.18)**: 転送前に電池残量を確認し、閾値未満かつ非充電なら待機 → 上限超過で安全停止 (`BATTERY_LOW_THRESHOLD_PCT` / `BATTERY_WAIT_MAX_SEC`)。ADB 切断時は一定時間再接続を粘り、復旧不能なら失敗分を `PENDING` に戻して安全停止 (`ADB_RECOVERY_WAIT_SEC`)。通常運転のオーバーヘッドを抑えるため、接続確認は転送失敗時のみ実施 (オンデマンド)。
- **切断解析ログ (v1.7.18)**: 同期中に 10 分間隔で残量 / 温度 / 空き容量を `logs/health.jsonl` へ記録 (ハートビート)。復旧不能な切断時は `logs/disconnect_*.log` にスナップショットを保存し、電池切れか突発切断かを事後に切り分け可能。
- **統計ページの分析専用化と時系列グラフ (v1.7.19)**: 期間切替 (24時間 / 7日 / 30日) 付きの自作 SVG グラフ 5 種 (転送量 GB/h・件数 (写真/動画)・実効速度 MB/s・電池残量・温度)。新 API `/api/stats/timeseries`。
- **転送完了時刻の記録 (v1.7.19)**: `files.transferred_at` を転送 DONE 時に記録 (件数の時間別集計用)。索引を追加。
- **ファイル一覧の移設 (v1.7.19)**: 統計ページから **管理ページ** へ移設 (列ごとの絞り込み / 検索 / 並べ替え)。
- **設定ページの再編 (v1.7.19)**: バッチ工程順の 9 グループに再構成し、各グループ／項目に説明を常時表示。難解な内部用語 (旧来の挙動 / 受理ルール B 等) を平易な表現に置換。

### v1.9.0 — macOS / Linux 対応 (ベストエフォート)

- **macOS / Linux 対応 (v1.9.0)**: これ まで Windows 専用 だっ た 構成 を macOS / Linux で も 起動 ・ 実行 でき る よう に し た (ベストエフォート)。実機 の macOS で の 動作 確認 は 未 実施。
- **ファイル マネージャ 起動 の OS 分岐 (v1.9.0)**: `open_in_file_manager()` を `core/util.py` に 追加。Windows は `os.startfile`、macOS は `open`、Linux は `xdg-open` を 使い分け 、 Web UI の 「フォルダを開く」 が macOS / Linux で も 動作 する よう に し た。
- **POSIX 起動 ランチャー の 追加 (v1.9.0)**: `source/bin/` に `.sh` / `.command` ランチャー (`start_web_app` / `start_app` / `db_admin` / `run_tests`) を 追加。`.sh` は macOS / Linux の ターミナル 用 、 `.command` は macOS の Finder から ダブルクリック する 用 で 対応 する `.sh` へ 委譲 する。`.venv/bin/python` が あれ ば それ を 、 無けれ ば `python3` を 使用 する。既存 の Windows `.cmd` ランチャー は 変更 し て い ない。
- **依存 定義 の 集約 (v1.9.0)**: リポジトリ 直下 に `requirements.txt` を 追加 (`fastapi` / `uvicorn[standard]` / `jinja2` と テスト 用 `pytest`)。
- **改行 コード の 固定 (v1.9.0)**: リポジトリ 直下 に `.gitattributes` を 追加 し 、 `*.cmd` / `*.bat` は CRLF、`*.sh` / `*.command` は LF、`*.zip` / `*.db` は バイナリ と し て 扱う よう に し た。
- **既知 の 制限 (v1.9.0)**: SMB / NAS セッション 維持 ヘルパー (`core/util.py`、`net.exe` 使用) は Windows 専用 の ため macOS / Linux で は スキップ さ れる。macOS / Linux 対応 は ベストエフォート で あ り 、 実機 macOS で の 動作 確認 は 未 実施。

### v1.8.0 — 製品名 改称 (NAS2GP)・DB パス変更・デバイス呼称の一般化・削除処理の安全化

- **製品名 の 改称 (v1.8.0)**: 製品名 を **NAS2GP** に 変更 (表示名・リポジトリ名・バックアップ名 を 含む)。特定 ブランド の 商標 を 製品名 に 含め ない 構成 と し た。
- **DB ファイル 名 の 変更 (v1.8.0)**: `database/pixel_sync.db` → `database/nas2gp.db`。初回 起動 時 に 旧 DB を 検出 し た ら 自動 で リネーム し (WAL / SHM 含む)、転送 履歴 を 引き継ぐ。
- **デバイス 呼称 の 一般化 (v1.8.0)**: UI ラベル ・ コンソール ログ の 「Pixel」 を 一般 デバイス 語 「端末」(英語 UI は "device") へ 置換。特定 機種 に 限定 さ れ ない 表現 と し た。
- **内部名 の 全面 改名 (v1.8.0)**: パッケージ名 `pixel_sync` → `nas2gp`、モジュール `pixel.py` → `device.py`、テンプレート `pixel.html` → `device.html`、クラス `Pixel` → `Device`、設定キー `PIXEL_*` → `DEVICE_*`、環境変数 `PIXELSYNC_*` → `NAS2GP_*` へ 統一 し た 。 旧 config キー は 読み込ま ない が 、 不足 キー は 既定 値 で 自動 補完 さ れる ため 手動 修正 は 不要 。
- **削除処理 の 安全化 (v1.8.0)**: 個人 の 写真 を 巻き込む 恐れ の ある 「/sdcard/DCIM 全体 削除」 を 撤廃。 削除 は NAS2GP が 端末 へ 転送 し た ファイル 単位 (1 件 ずつ `rm -f`) のみ と し 、 容量不足 時 の 復旧 も 「転送済みファイル 削除 → 再起動」 の 2 段 に 変更。 管理画面 の 手動 削除 も 「転送 し た ファイル のみ 削除」 へ 置換。
- **Web URL の 一般化 (v1.8.0)**: 端末ページ の URL を `/pixel` から `/device` へ 、 関連 API を `/api/pixel/*` から `/api/device/*` へ 変更 し た (ブラウザ の アドレス に 特定 ブランド 名 を 残さない)。
- **Web 画面 に バージョン 表示・製品 バージョン の 一元化 (v1.8.0)**: 全ページ の ヘッダー 右上 に ソフト バージョン を 表示 (ヘッダー の 方式 / バッチ目標 の 行 も 白文字 に して 視認性 を 改善)。 製品 バージョン は `settings.py` の `APP_VERSION` に 一元化 し 、 Web 表示 ・ OpenAPI(`/docs`) ・ 診断 が 同じ 値 を 参照 する よう に し た 。 併せて 、 更新 が 止まっ て い た 各 ファイル 先頭 の `# VERSION:` / `# UPDATED:` コメント と 未使用 の `VERSION` 定数 を 削除。
- **作業フォルダ の 動的選択 (v1.8.0)**: 端末側 の 転送先 兼 削除 対象 を 「作業フォルダ」 と 呼び 、 既定 を `/sdcard/DCIM/NAS2GP` に 変更。端末ページ から DCIM 配下 の フォルダ を 選んで 変更 でき る よう に し た (設定 `DEVICE_WORK_DIR` / config スキーマ 10)。転送前 に フォルダ が 無けれ ば 自動作成 する。これ に 伴い 未使用 と なっ た DCIM フォルダ一覧 API / メソッド を 撤去。
- **リポジトリ構成の変更 (v1.8.0)**: ソースコードを `source/` 配下に集約し、リポジトリ直下には `README.md`・`LICENSE`・`docs/`・`source/`・`archive/` を置く構成とした。`archive/` にはリリース版の zip (`NAS2GP_v1.8.0.zip`) を保存する。

### v1.7.20 — 用語統一・履歴クリア・管理画面再配置・配布レイアウト平坦化
