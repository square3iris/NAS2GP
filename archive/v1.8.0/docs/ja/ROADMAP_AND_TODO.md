## 3. Phase 8 — 次期開発 (ROADMAP)

Web UI 一本化の完了により、配布と運用まわりを強化するフェーズです。

### 3.1 優先度 最高
- [ ] **単一ファイル配布 (PyInstaller)**: `entry_web.py` を `.exe` 化。初回起動時に `config/` と `database/` を自動生成。fastapi / uvicorn / jinja2 の hidden import、アイコン同梱、`adb.exe` の同梱または自動ダウンロード。
- [ ] **更新チェッカー**: 起動時に GitHub Releases (または NAS) の最新タグを確認し Web UI にインライン通知。自動強制更新は行わない。

### 3.2 優先度 高
- [ ] **複数 端末 の並列同期**: シリアル指定をリスト化し、デバイスごとに同期ワーカースレッドを起動。画面はデバイス切替式に。
- [ ] **Wi-Fi 無線 ADB 対応**: `adb tcpip 5555` + `adb connect` による自動接続 / 切断。設定ページに IP 設定を追加。
- [ ] **転送前の厳密ハッシュ (SHA-256)**: 重複排除のハッシュ判定を実装 (DB に列追加)。

### 3.3 優先度 中
- [ ] **削除ファイルのゴミ箱移動**: `rm` の代わりに一時退避領域へ移動し、任意の復元期間を設ける。
- [ ] **バックアップ受理ルールの可視化**: 受理状況を色分け表示。

### 3.4 優先度 低
- [ ] **Web サーバーの常駐 / 自動起動**: スタートアップ登録でログイン後に自動起動。
- [ ] **外部通知 webhook**: Slack / Teams / LINE などへ完了時に通知。
- [ ] **ディスク空き容量監視**: PHOTO_DIR 側の残量が少ない場合に診断ページで警告。
